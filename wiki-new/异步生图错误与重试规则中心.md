# 异步生图错误与重试规则中心

## 管理入口

管理员从侧栏「异步生图任务」旁打开「错误与重试规则」，路径为 `/admin/async-image-retry-rules`。中心覆盖持久异步 OpenAI BB、Gemini BB/SC 及同一任务链路的图片工作台。旧异步图片、图片批处理和 Grok 视频使用各自的处理流程。

1. 在「错误样本」按时间、平台、模型、阶段、失败账号或决策来源筛选，从事件详情创建规则。
2. 编辑规则的**失败来源**和**重试目标**。规则可限定来源分组、来源账号、阶段、分类、HTTP 状态、上游错误码及脱敏消息。重试目标允许和排除名单只作用于任务原分组的兼容账号池。
3. 用文字、单条历史事件或当前页样本预览。文字预览评估匹配。历史事件结合当前用量和可读取的候选账号快照。账号并发槽、实时健康及真实派发仍由 Worker 判定。
4. 点击「保存并生效」。列表顺序是匹配优先级。第一条命中规则接管本次处理，用尽后按该规则的结束动作处理。调整优先级、复制及启停都先改草稿。修改冲突时保留草稿，加载当前版本后重新比较。
5. 在「版本」对比配置快照。回滚以当前修订号提交，生成新的修订号。已消耗的规则和步骤次数继续按稳定 ID 累计。

## 动作和限制

| 动作 | 条件 |
|---|---|
| 原账号重试、换账号重试 | 生成可以安全重提。原账号必须精确匹配，换账号排除失败账号。实际调度仍检查 Key、分组、模型、档位、账号健康、容量和请求能力 |
| 下载参考图后原账号或换账号 | 图生图且已保留可用参考图，复用原文件与顺序、SSRF 校验、大小限制和平台传输方式 |
| 重试素材准备 | 本站素材准备仍可恢复，开始准备时计入步骤次数 |
| 恢复下载、保存或结算 | 已有结果或账务证据，继续执行当前后处理 |
| 停止或转人工 | 已产出及执行结果未知遵守保护规则，相关证据保留并从管理员任务详情继续核对 |

管理员任务详情展示「等待规则执行」或「待人工核对」。处于人工核对的结果下载任务，只有失败仍可重试、下载预算有余额且加密结果快照仍有效时，才提供「恢复后处理」。恢复保留各张图片已使用的下载次数。过期快照按原保留期限清理，任务和决策事件可继续核对。

默认规则为空且替代生成暂停关闭。没有自定义规则命中时运行已有策略。步骤支持固定和指数退避，默认固定。每个步骤 1–16 次，等待及上限 0–1800 秒。规则总次数取 0 时合计各步骤额度，默认耗尽后转人工。规则数量上限 200，每条最多 8 步，配置最多 1 MiB。生成仍受任务级预算、最多 16 次派发和提交后 30 分钟的限制。后台暂停将暂缓新的替代生成，首次生成与已有结果的恢复处理可继续。由于持久链路使用同步上游，发送后结果未知进入 `execution_unknown` 待核对。

规则示例，匹配明确的 Gemini 参考图下载错误，先按任务原分组换到另一个兼容账号尝试一次。

```json
{
  "id": "gemini-reference-timeout",
  "name": "Gemini 参考图下载超时换账号",
  "enabled": true,
  "scope": { "platforms": ["gemini"], "stages": ["submit"] },
  "match": {
    "http_statuses": [454],
    "error_codes": ["asset_download_timeout"]
  },
  "steps": [
    {
      "id": "alternate",
      "action": "other_account",
      "max_attempts": 1,
      "delay_seconds": 3,
      "backoff": "fixed"
    }
  ],
  "max_attempts": 1,
  "on_exhausted": "manual_review"
}
```

## 执行与审计

- 逐次上游失败由 OpenAI API Key、OAuth 和 Gemini 适配器提供协议事实。Worker 按规则决定下一动作，继续使用 PostgreSQL 任务版本、Outbox、Redis 投递和已有后处理链路。等待期间完成的规则更新在派发前生效，派发后按原尝试处理。
- 错误样本保留七天。样本对同一失败的多次规则评估去重。执行次数使用动作开始事件，后续成功任务数按任务 ID 去重。默认策略同样可以产生实际执行和后续成功。历史上下文缺失时可查看事件快照。
- API 前缀为 `/api/v1/admin/async-image-retry-rules`，配置读取和保存使用 GET/PUT，预览和回滚使用 POST，样本、事件、版本使用 GET。后台认证与任务中心相同，预览请求不进入通用操作审计正文。详细公共接口与客户端查询见[异步生图接口文档](../异步生图接口文档new.md#53-重试边界)。
